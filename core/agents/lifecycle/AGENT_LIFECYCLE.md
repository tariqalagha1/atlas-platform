# Agent Lifecycle

## States

1. Draft
2. Configured
3. Activated
4. Running
5. Paused
6. Archived

## Required Files Per Agent

- operating-manual.md
- mission.md
- permissions.md
- memory-policy.md
- skills-policy.md
- model-policy.md
- task-log.md

## Activation Rule

No agent should be activated until:

- Workspace exists
- Hermes profile exists
- Rules exist
- Operating manual exists
- Backup path exists
